DOC. 002  Alcove / what it is, and how it works Rev. 2026  ·  Version 0.2.9

Organize your desktop into drawers.

Alcove is a free Windows desktop organizer made by Cromis. Put your work documents in one drawer, app shortcuts in another, or group everything for a project together. One drawer opens at a time. Close it when you're done. Your files stay where they are. Alcove changes how you see them on the desktop, with a layout for each monitor and colours that match your wallpaper.

01 What it does Drawers and shortcuts

A place for the files you're working with.

Alcove replaces the desktop icon grid with named drawers. Your taskbar and apps work as usual, and you can return to the standard Windows desktop.

1.1

Start with the icons you already have

On first run, Alcove offers to sort your desktop icons into Apps, Documents, Photos, Folders and Installers. You can also sort them yourself. New files saved to the Desktop appear in the Inbox, ready for you to put in a drawer. Drag an icon onto empty wallpaper to return it to the Inbox.

1.2

One drawer open at a time

Your drawers sit in a rail along the side of the desktop. Click a drawer to open it. Click again to close it, or open another drawer to switch. Each tile shows a name and item count. Hover to check disk usage, and drag tiles up or down to put them in the order you want.

1.3

Room for larger projects

Drawers with up to twelve items open as compact panels. Larger ones spread across the desktop as a canvas, with rows you can name: This week, Client A, or whatever makes sense for your work. Drag icons between rows to organize them. You can also choose either view in the drawer header and keep it.

1.4

Keep your usual apps and files close

The frequent strip sits at the top or bottom of your desktop and shows what you open most. It adjusts as your habits change, giving less weight to older activity. Items keep their slots while their rankings change, so shortcuts don't shuffle around as you use them. Choose Keep in this slot to pin something, or ban an item you don't want in the strip.

02 The look Light and dark

It takes its colour from your wallpaper.

A blue wallpaper gives Alcove a blue tint. A dark photo gives it darker panels. The colour comes from the image as a whole, so a small bright detail won't set the colour for the entire desktop.

The rail, frequent strip and drawers let some of the wallpaper show through. Search, menus and dialogs use solid backgrounds so the picture doesn't interfere with the text.

In Settings, Surface lets you choose Blend, Tinted (the default) or Solid. Text size scales the labels, and Stronger text gives smaller labels more contrast. To change your wallpaper, right-click the desktop and choose Background. Pick an image from your folders or use a flat colour. This changes the Windows wallpaper on every monitor, and it stays after you close Alcove.

03 Search Four lists, one window

Ctrl Space from anywhere in Windows

Open search while you're working in another app, without switching to the desktop first. It finds files, drawers and running windows. When two results match about equally well, the one you use most appears first.

3.1

Get back to a recent file

Before you type, search shows Today, for files changed since midnight, and Frequent, for things you open most. Press 1–9 to open a numbered result. File type, size and modification time help you tell similar names apart. Today shows at most two pictures, leaving room for documents after a batch of image downloads.

3.2

Type > for commands

Create a drawer, change the wallpaper or open Settings from the search window. Commands also let you collapse drawers, toggle the taskbar and empty the Recycle Bin. Windows still asks for confirmation before emptying it. Keyboard shortcuts are listed beside the commands.

  • Icons, on the desktop and in every drawer.
  • Running windows. Search by name and select a window to switch to it.
  • Drawers, by name. Enter opens the drawer on its monitor.
  • Files inside linked folders. Search also checks subfolders, starting with the nearest ones. It stops after about half a second and returns what it found, so large folders may have more matches. It skips node_modules, AppData and the Recycle Bin.
  • Labelled results separate files, windows and drawers.
  • Ctrl+Enter shows the file in Explorer. Use Shift+Enter to open its containing folder.
  • Paths, commands and web addresses. Open a path directly, send a URL to your browser, or run a single-word command as you would with Win+R. A web search option is also available at the bottom.
  • Matching colours. Search uses the same wallpaper-based colours as the desktop drawers.

04 Working with Windows Files and settings

Your files are still Windows files.

Alcove reads your Desktop folder and uses Windows to open files. You can also add drawers for other folders, including Downloads and USB drives.

  • Your usual apps. Files open with their Windows file associations. The icon pulses while the app starts.
  • Folder drawers. Link a drawer to Downloads or a project folder to browse its contents. Choose icons, a list or a details view with sortable columns. Press Backspace to go up a folder.
  • USB drives. Plug in a drive and a drawer appears with its name. Use eject to safely unmount it. If a file is still in use, Alcove reports that the drive couldn't be ejected. The drawer closes when you unplug it and isn't saved between runs. You can turn USB drawers off in Settings.
  • The Windows taskbar. Running apps stay on your normal taskbar.
  • The Recycle Bin. Right-click it for the standard Windows menu.
  • Wallpaper settings. You can also open Windows' own background settings from Alcove's menu.
  • Multiple monitors. Each screen saves its own layout. Drag a drawer to another monitor to move it there.
  • Grouping doesn't move files. Assigning a desktop icon to a drawer changes Alcove's layout, not the file's location.
  • Local settings. Layouts, drawers and pins are saved in %APPDATA%\com.alcove.desktop\desktop.json. Deleting that file resets your Alcove setup without deleting your desktop files.
  • Back to Explorer. Ctrl+Shift+F12 releases the desktop back to Windows Explorer if you need to stop using Alcove.
  • No account or telemetry. Organizing and opening local files works offline. Alcove uses the internet to check for and download updates. Web addresses and web searches open in your browser.

Double-click the wallpaper to create a drawer, called an Alcove in the app. Right-click for Paste, New Alcove, Collapse all and Background. You can drag an icon onto a drawer to group it, onto the corner pins to keep it in place, or onto empty wallpaper to return it to the Inbox. Drop a file on an app in the frequent strip to open it with that app.

06 Licence MIT

Free to use, with the source on GitHub.

Alcove is released under the MIT licence. You can install it at home or at work, inspect the code and build your own version.

Cost

All features included

Use Alcove on as many machines and monitors as you like. There's no paid edition, trial period or licence key.

Permissions

Make it your own

You can modify and redistribute Alcove, including in commercial projects. Keep the copyright and licence notices with any copies you distribute.

Activation

No sign-in needed

Install it and use it. Alcove doesn't contact a licence server or require an account, and you can organize your desktop offline.

Alcove is built with Tauri, React and Rust, each under its own licence.
