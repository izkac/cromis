Alcove vs Fences: features and limitations.

Alcove and Stardock Fences organize Windows desktop icons in different ways. Fences groups them in shaded areas on Explorer's desktop. Alcove replaces the icon view with named drawers, one open at a time. Fences has been available since 2009 and has passed twenty million downloads. Alcove is Cromis's free, open-source alternative, built by one person and currently at version 0.2.9. This comparison covers both approaches, including features Alcove lacks and reasons you might prefer Fences.

01 Desktop layout Groups and drawers

How each app uses the desktop.

Fences keeps Explorer's icon grid. Alcove replaces that view with its own interface while using the same Desktop files.

Fences

Regions drawn over Explorer's grid

Fences groups Explorer's desktop icons in shaded areas. You can keep several groups open, roll them up, arrange them across pages or stack them into tabs. Explorer's desktop remains underneath if Fences stops running.

Alcove

Drawers in place of the icon grid

Alcove displays named drawers on a rail in place of Explorer's icon grid. One drawer opens at a time, leaving space for your wallpaper. It reads your real Desktop folder and opens files through the Windows shell. Organizing icons in drawers doesn't copy or move the files. Ctrl+Shift+F12 restores Explorer's desktop immediately.

Fences makes a smaller change to the Windows desktop. Alcove replaces more of the interface, adding a drawer rail, an automatically populated frequent strip, search and wallpaper-based colours. Use one app at a time, since both control the desktop.

03 Buy Fences Five good reasons

When to choose Fences.

Fences is the better fit if you need its grouping features, configurable filing rules or a signed installer. It also has a much longer release history.

  • You prefer an established app. Fences has been available for seventeen years and has passed twenty million downloads. Alcove has had a few months of development, so you should expect some undiscovered bugs.
  • You need roll-up, pages or tabs. Fences supports all three. Alcove has none of them, and we haven't committed to adding them.
  • A SmartScreen warning is a dealbreaker. Alcove isn't Authenticode-signed yet, so Windows may warn when you first run it. The code signing page explains its current signing status.
  • You need configurable filing rules. Fences has a broader rules engine. Alcove offers first-run sorting and an Inbox for new desktop items.
  • You already own Object Desktop. Fences is included, so you may already have access to it.

04 Try Alcove Five good reasons

When to try Alcove.

Try Alcove if you prefer a drawer-based desktop or want a free app whose source you can read and modify.

  • You want access to the source. Alcove's code is on GitHub under the MIT licence, so you can inspect how it works and change it.
  • You want a free app without activation. Use every feature across your monitors, on as many machines as you like. There's no licence key or activation server.
  • You prefer one drawer open at a time. The layout leaves room for your wallpaper, with colours drawn from it for the rail, strip and drawers.
  • You prefer keyboard search. Ctrl+Space searches icons, drawers, folders and running windows from anywhere in Windows. Type > to use the command palette in the same window.
  • You want to switch back quickly. Ctrl+Shift+F12 restores Explorer's desktop immediately. Your layout is stored in one JSON file you can delete to reset it.
